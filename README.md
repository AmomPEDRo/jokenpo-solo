 🪨📄✂️ Jogo Pedra, Papel e Tesoura (CLI)

Este é um simples jogo de **Pedra, Papel e Tesoura** que roda no terminal, escrito em Python. O jogador faz sua escolha, o computador escolhe aleatoriamente, e o resultado é exibido na tela.

## 📋 Requisitos

- Python 3.x instalado em seu sistema

## 🚀 Como jogar

1. Clone este repositório ou copie o código para um arquivo `.py` local:
    ```bash
    git clone https://github.com/seu-usuario/jogo-pedra-papel-tesoura.git
    cd jogo-pedra-papel-tesoura
    ```

2. Execute o jogo no terminal:
    ```bash
    python jogo.py
    ```

3. Você verá um prompt pedindo para escolher entre `pedra`, `papel` ou `tesoura`.

4. O computador fará sua escolha e o resultado será exibido:
    - Empate
    - Você venceu!
    - Você perdeu!

## 🧠 Lógica do jogo

- Pedra ganha de Tesoura
- Tesoura ganha de Papel
- Papel ganha de Pedra
- Se ambos escolherem o mesmo, é empate

## 💡 Exemplo de execução

```
Escolha entre Pedra, Papel ou Tesoura: papel  
Computador escolheu: pedra  
Você venceu!
```
